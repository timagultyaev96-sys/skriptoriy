# Скрипторий

Карточки и упражнения для изучения английского: интервальное повторение, тесты, игра «Пары», пропуски в предложениях, перевод фраз и учёт трудных слов. Проводница — сестра Элиана.

Весь сайт — один файл `index.html`. Сервер и регистрация не нужны: колоды и прогресс хранятся в браузере.

## Учитель и ученики

- Каждый выбирает роль в настройках (шестерёнка вверху).
- Учитель создаёт колоду и нажимает «Поделиться» — получается ссылка, которую можно отправить ученику.
- Ученик открывает ссылку, и колода появляется в разделе «Задания от учителя».
- Ученик нажимает «Отчёт учителю» и отправляет ссылку обратно; учитель видит прогресс и слова, которые даются плохо.

## Как опубликовать

1. Откройте **Settings → Pages** этого репозитория.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
